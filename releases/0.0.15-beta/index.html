    TheCleaners 0.0.15-beta

    Published prerelease. Gallery version 0.0.15-beta and Git tag v0.0.15-beta identify exact source commit 345f06c861b6d4074e5896e0b27a19f869dfa7e3 and its approved tested artifact.

    Install-Module -Name TheCleaners -Repository PSGallery -RequiredVersion '0.0.15-beta' -AllowPrerelease

    This beta prepares the 1.0 command and safety contracts for Windows PowerShell 5.1 and supported PowerShell 7 releases on Windows. It includes temporary-file maintenance, typed results, quiet imports, the Get-TheCleaners command inventory, and deterministic source-layout packaging.

    Changes and compatibility

    • Temporary-file deletion uses opened file identities and reports proposed, removed, skipped and failed candidates. Errors remain visible through PowerShell's error stream.
    • Empty-directory pruning is opt-in with -RemoveEmptyDirectory and limited to directories emptied by that invocation and their qualifying ancestors.
    • Get-TheCleaners replaces Start-Cleaning; the old name remains a deprecated alias through 1.x. Neither command starts cleanup. Module import is quiet.
    • Stale-profile discovery returns typed, read-only results with explicit unknown-date handling and optional sizing.
    • IIS and Exchange discovery require explicit -WhatIf and remain structurally deletion-disabled. Exchange no longer invokes IIS cleanup. No force flag, activation setting or Exchange removal switch is available.
    • Published package verification uses the exact tested module content, archive digest and source identity. Help and documentation use the canonical title-case site.

    See the migration guide for parameter and behavior changes and the repository changelog for the complete preparation history.

    Validation limits

    Windows client/server, filesystem/privilege, profile, IIS and Exchange lab validation is deferred future work and is not underway. Hosted fixture and package tests do not establish product acceptance. IIS/Exchange candidate lists remain experimental. This beta does not establish production-ready 1.0 support or enable server-log deletion.

    Exact candidate, publication and installed-package evidence is recorded in the release ledger. Prior runtime/archive evidence remains bound to its original commit; it is not reused as proof for this package.

    Release-history reconciliation

    Before this release, the September 17, 2026 inventory found Gallery versions 0.0.6-alpha through 0.0.13-alpha, with 0.0.13-alpha then latest. Version 0.0.15-beta was unused before the approved publication. No Git tags existed at that earlier check.

    An earlier inventory recorded unpublished draft release ID 172666498, titled Testing and Workflow Updates and labeled 0.0.11-alpha; its label did not resolve to a Git tag. It was not reused for this beta, and no historical package is assigned to the current source commit without evidence. After the beta prerelease was created, the full release inventory returned only new release ID 391037563 and a direct read of the older ID returned 404. The beta creation command targeted only v0.0.15-beta; no old-draft deletion was requested, and the cause of its disappearance is unknown.

    The protected publisher rechecked the exact candidate version and would refuse publication if that required version already existed in the Gallery. Local-feed rehearsal, actual Gallery publication, and fresh Gallery installation remain separate evidence checkpoints in the release ledger.
